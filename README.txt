To publish with GitHub Pages:
1. Create a new GitHub repository (for example: fick-calculator).
2. Upload all four files to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main and / (root), then Save.
6. Open the published HTTPS address in Safari on your iPhone.
7. Tap Share > Add to Home Screen. Enable Open as Web App if shown, then tap Add.

Clinical note:
This uses the simplified Fick calculation and omits dissolved oxygen.
Use your institution's validated hemodynamic method for patient-care decisions.
